# F. Perbandingan Pedekatan Native, Hybrid, dan Cross-platform
Pendekatan Native melibatkan pembuatan aplikasi khusus untuk satu platform menggunakan bahasa spesifik (seperti Kotlin untuk Android atau Swift untuk iOS). Pendekatan ini menawarkan performa tertinggi dan akses penuh ke perangkat keras (hardware), namun membutuhkan biaya dan waktu yang besar karena kode harus ditulis terpisah untuk setiap platform. Sebaliknya, pendekatan Hybrid membangun aplikasi menggunakan teknologi web (HTML, CSS, JavaScript) yang dibungkus dalam wadah WebView. Pendekatan ini sangat efisien untuk pengembangan lintas platform, tetapi performanya cenderung lebih lambat dan interaksi antarmukanya kurang mulus. Sebagai titik tengah, pendekatan Cross-platform (seperti menggunakan Flutter) memungkinkan pengembang menulis satu basis kode (single codebase) yang dikompilasi langsung menjadi kode mesin native menggunakan mesin rendering tersendiri. Ini memberikan performa yang hampir setara dengan native dengan efisiensi waktu yang tinggi.
